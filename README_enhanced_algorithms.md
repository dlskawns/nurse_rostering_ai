# 개선된 CP-SAT 근무표 생성 알고리즘

## 📋 개요

이 프로젝트는 간호사 근무표 생성을 위한 CP-SAT(Constraint Programming - Satisfiability) 기반 알고리즘들을 개선한 버전입니다. 법규 제약사항과 병원 내규를 명확히 구분하여 처리하며, Night Keep과 Evening 근무의 가중치를 차별화했습니다.

## 🏥 제약사항 분류

### 법규 제약사항 (Hard Constraints)

이는 반드시 지켜져야 하는 법적/안전 요구사항입니다:

| 제약사항            | 설명                                     | DB 컬럼명                  |
| ------------------- | ---------------------------------------- | -------------------------- |
| 최대 연속 근무일 수 | 5일(40시간) 초과 근무 금지               | `max_conseq_work`          |
| E → D 근무 금지     | Evening 근무 뒤 최소 11시간 휴식 확보    | `banned_day_after_eve`     |
| N 연속 3회 허용     | Night 근무를 최대 3회까지 연속 배정 가능 | `three_seq_nig`            |
| N 3회 후 OFF 2회    | N 3회 연속 뒤 OFF 2회 연속 배정 의무     | `two_offs_after_three_nig` |
| N 2회 후 OFF 2회    | N 2회 연속 뒤 OFF 2회 연속 배정          | `two_offs_after_two_nig`   |
| 월 최대 N 근무 수   | 한 달 Night 근무 총량 상한               | `max_nig_per_month`        |

### 병원 내규 (Soft Constraints)

이는 가능한 만족시키려 하지만, 위반 시 패널티로 처리되는 요구사항입니다:

| 제약사항                | 설명                                        | DB 컬럼명           |
| ----------------------- | ------------------------------------------- | ------------------- |
| Shift 내 책임 최소 경력 | 한 교대당 책임 간호사가 갖춰야 할 최소 연차 | `min_exp_per_shift` |
| 책임 간호 인원          | Shift당 위 연차 이상 경력간호사 최소 인원   | `req_exp_nurses`    |
| 주 2회 이상 OFF         | 주간 OFF를 최소 2회 이상 편성               | `two_offs_per_week` |
| OFF 연속 배정           | OFF 배정 시 연속으로 묶어 배정              | `sequential_offs`   |
| N 개수 균등 배정        | Night 근무를 인원 간 균등 분배              | `even_nights`       |

## 🛠️ 개선된 알고리즘들

### 1. CP-SAT Basic (Enhanced)

- **파일**: `cp_sat_basic.py`
- **특징**: 기본 CP-SAT 엔진에 새로운 제약사항들을 추가
- **장점**: 빠른 실행 속도, 안정적인 결과
- **권장**: 소규모 병동 또는 빠른 프로토타이핑

### 2. CP-SAT Main V3 (Enhanced)

- **파일**: `cp_sat_main_v3.py`
- **특징**: main_v3.py와 동일한 품질 + 새로운 제약사항
- **장점**: 선호도 처리 우수, 페어링 지원
- **권장**: 선호도가 복잡한 경우

### 3. CP-SAT Main V2 (Enhanced)

- **파일**: `cp_sat_main_v2.py`
- **특징**: main_v2.py 기반 + LNS 최적화 + 새로운 제약사항
- **장점**: 2단계 최적화로 품질 향상
- **권장**: 품질을 중시하는 경우

### 4. CP-SAT Adaptive (Enhanced)

- **파일**: `cp_sat_adaptive.py`
- **특징**: 점진적 완화 전략 + 제약 계층 관리
- **장점**: 복잡한 제약사항에서도 해 탐색 가능
- **권장**: 제약사항이 매우 까다로운 경우

## 🎯 가중치 차별화

### Night Keep vs Evening

- **Night (N)**: 7.0 (높은 가중치로 우선 배정)
- **Evening (E)**: 5.0 (기본 가중치)
- **Day (D)**: 5.0 (기본 가중치)
- **OFF**: 10.0 (높은 선호도 가중치)

## 🧪 테스트 및 튜닝

### 기본 테스트 실행

```bash
python test_enhanced_algorithms.py
```

이 스크립트는:

- 모든 개선된 알고리즘을 테스트
- 실행 시간과 결과 품질 분석
- 제약사항 위반 여부 체크
- 가장 빠른 알고리즘 추천

### 가중치 튜닝 실행

```bash
python tune_algorithm_weights.py
```

이 스크립트는:

- 다양한 가중치 조합 자동 테스트
- 결과 품질 점수 계산
- 최적 가중치 조합 추천
- 결과를 `tuning_results.json`에 저장

## 📊 성능 지표

### 평가 기준

1. **제약 위반 수**: 0개가 목표 (법규 제약사항)
2. **근무 균형도**: 간호사 간 근무량 표준편차 최소화
3. **선호도 만족률**: 휴무 요청 등 선호도 반영 정도
4. **실행 시간**: 60초 내 해 탐색 목표

### 일반적인 성능

- **소규모 병동** (5-10명): 모든 알고리즘 30초 내 완료
- **중규모 병동** (11-20명): Basic/V3는 60초 내, Adaptive는 120초 내
- **대규모 병동** (21명 이상): Adaptive 권장, 300초 제한

## 🔧 커스터마이징

### config.py 수정

새로운 제약사항을 추가하려면 `NurseRosterConfig` 클래스에 필드를 추가:

```python
@dataclass
class NurseRosterConfig:
    # 기존 필드들...

    # 새로운 제약사항 추가
    your_new_constraint: bool = True
```

### 알고리즘 수정

각 알고리즘 파일에서 `_optimize_with_enhanced_constraints()` 메서드를 수정하여 새로운 제약사항 로직을 추가할 수 있습니다.

## 🚀 프로덕션 배포

### 권장 설정

1. **일반적인 병동**: CP-SAT Basic (Enhanced)
2. **복잡한 선호도**: CP-SAT Main V3 (Enhanced)
3. **높은 품질 요구**: CP-SAT Main V2 (Enhanced)
4. **까다로운 제약**: CP-SAT Adaptive (Enhanced)

### 시간 제한 설정

- **개발/테스트**: 30-60초
- **프로덕션**: 90-120초
- **일괄 처리**: 300초

## ⚠️ 주의사항

1. **OR-Tools 필수**: `pip install ortools` 설치 필요
2. **메모리 사용량**: 대규모 병동에서는 8GB+ RAM 권장
3. **해가 없는 경우**: 제약사항이 너무 엄격하면 해가 없을 수 있음
4. **백업 엔진**: 개선된 알고리즘 실패 시 기본 엔진으로 자동 폴백
